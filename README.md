# Hi, I'm Diptiman 👋

Electrical engineer working on signal processing and machine learning. Currently a **Project Associate at SPIRE Lab, Indian Institute of Science (IISc), Bangalore**, building ASR systems for low-resource Indian languages.

Before this: research stints at **IIT Kanpur** and **DIAT-DRDO, Pune**. B.Tech in Electrical Engineering from Parala Maharaja Engineering College, Berhampur.

## What I work on

- **Speech & NLP** — ASR for Indic languages, text normalization, character/BPE/SSM language models
- **Biomedical signals** — ECG/EEG classification, time-frequency analysis (VMD, DWT, STFT), signal-to-image methods
- **Deep learning** — complex-valued neural networks, U-Net segmentation, model explainability (SHAP, Grad-CAM)
- **Medical AI** — diagnostic systems, clinical data pipelines, explainable healthcare models

Day-to-day tools: Python, PyTorch, MATLAB, TensorFlow, Hugging Face, and a soldering iron when the work calls for Arduino or Raspberry Pi.
